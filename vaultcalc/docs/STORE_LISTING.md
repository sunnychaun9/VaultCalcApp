## Policy Compliance Notes

### Language Deliberately Avoided

| Banned Phrase | Why | Used Instead |
|---|---|---|
| "No one will ever know" | Implies deception | "Designed for personal privacy" |
| "Completely hidden" | Violates Deceptive Behavior policy | "Optional app appearance setting" |
| "Secret calculator" | Implies concealment is the purpose | "Fully functional calculator" |
| "Invisible" / "Undetectable" | Deceptive behavior | "Always remains visible in your launcher" |
| "Military-grade encryption" | Unverifiable marketing claim | "AES-256-GCM — the same standard used by financial institutions" |
| "100% secure" / "Unbreakable" | No security is absolute | "Industry-standard encryption" |
| "Hide from [anyone]" | Implies adversarial concealment | "Personal privacy on shared devices" |

### Key Compliance Decisions

1. **"WHAT THIS APP IS NOT" section** — Proactively addresses reviewer concerns about deceptive behavior. Establishes that the app does not circumvent device management or parental controls.

2. **"App Appearance" disclosed as cosmetic** — The disguised icon feature is explicitly described as optional and always explained during onboarding. The listing states the app "always remains visible in your launcher and app list."

3. **"This access method is fully disclosed"** — The PIN-in-calculator vault access is described transparently, with an explicit note that it is explained during setup.

4. **Permissions justified individually** — Each dangerous permission has a clear, non-evasive explanation tied to a specific feature.

5. **No emotional manipulation** — No fear-based language ("protect yourself from snoopers"), no urgency ("before it's too late"), no guilt ("you deserve privacy"). Straightforward feature descriptions only.

### Reviewer Anticipation

If a reviewer flags the disguised icon feature:
- The listing discloses it under "APP APPEARANCE"
- Onboarding shows an explicit disclosure message
- The app always keeps at least one launcher entry visible
- Similar apps (Calculator Lock, Private Calculator) have 10M+ installs with the same pattern

If a reviewer flags the calculator-as-vault-entry pattern:
- The listing explains the full flow under "HOW IT WORKS"
- The phrase "fully disclosed to you during setup" is included
- The "WHAT THIS APP IS NOT" section preempts bad-faith interpretations
